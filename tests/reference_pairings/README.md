# Reference pairing matrices

These CSV files are the golden pairing matrices for packed Lyndon-word groups
with alphabet / length bound `n = 4`.

## Provenance

1. Matrices were **generated by this project's code** (`Word.grouped_lyndon_words`
   + `PairingMatrix`).
2. Each matrix was then **checked by hand** against independent computations
   done for the thesis. They are therefore effectively hand-verified goldens.

Treat this directory as the source of truth for pairing-matrix regression tests.
Do not overwrite files here without re-checking against those independent
computations.
